# FitCore Gym Management System

A static frontend for a university database systems project. It includes forms and report views for members, employees, trainers, membership plans, classes, enrollments, and payments.

The **Task C Data** page integrates sample database records reconstructed from the Phase 3 PDF report. The current site is a frontend demonstration; the forms do not persist data until a MySQL backend is connected.

## Run locally

1. Install Node.js.
2. Run `npm install`.
3. Run `npm start`.
4. Open `http://localhost:3000`.

## Project contents

- `public/` - current FitCore website
- `TaskB-html-only/` - earlier HTML-only deliverable
- `output/pdf/TaskB.pdf` - PDF version of the Task B deliverable
